# Fotos für den Bericht

Fotos genau unter diesen Namen hier ablegen. `main.tex` bindet sie automatisch ein.
Fehlt eine Datei, steht im PDF ein roter Platzhalter. Andere Endungen gehen auch, dann aber den
Namen in `main.tex` anpassen. JPG/PNG unter etwa 2 MB halten, HEIC kann pdfLaTeX nicht lesen.

| Datei | Motiv |
|---|---|
| `interaktion_karte.jpg` | Hand hält die Karte ans Lesefeld, Display zeigt „Hallo Anna“ |
| `prozess_skizze.jpg` | erste Skizze oder Pitch-Folie |
| `prozess_breadboard.jpg` | Breadboard mit ESP32, Servo und LCD beim Einzeltest |
| `prototyp_gesamt.jpg` | fertiger Prototyp von vorne: drei Kammern, Display, Becher, Lesefeld |
| `mechanik_kammer.jpg` | eine Kammer offen: Magazin, Schieber, Servo |
| `gehaeuse_innen.jpg` | Gehäuse von innen mit Verkabelung |
| `becher_kupfer.jpg` | Grundplatte mit den zwei Kupferflächen und Becher mit Kupferband |
| `mikrofon.jpg` | Mikrofonmodul unter den Kammern |
| `screenshot_nutzer.png` | Website, Nutzerbereich „Heute“ mit Statuskarte |
| `screenshot_verwaltung.png` | Website, Verwaltung oder Demo-Dashboard |
